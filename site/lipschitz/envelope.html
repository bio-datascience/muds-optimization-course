FunctionEnvelope

Move the point along the curve. The entire function stays inside the envelope.

A function is \(K\)-Lipschitz if

\[|f(x)-f(y)|\le K|x-y|\quad(x,y\in\mathcal X).\]

One observed value \(f(c)\) bounds the function everywhere:

\[\begin{aligned}f(x)&\ge f(c)-K|x-c|,\\f(x)&\le f(c)+K|x-c|.\end{aligned}\]

Lower and upper bounds, not tangent lines.

Here \(K=2\), \(\mathcal X=[-3,3]\).
Convexity is not required.
