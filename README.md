# MUDS optimization course

Christian L. Müller · 23 November 2026 · six 45-minute chapters.

Browser lecture with progressive reveals, locally bundled equation rendering, and interactive optimization demonstrations.

Open `site/index.html` through a static web server. GitHub Pages publishes `site/` through the included workflow; select **GitHub Actions** in Settings → Pages.

The published site is a snapshot of the maintained course project. Original six PDFs, downloaded papers, private work history and scratch files are excluded. Edit the maintained project, then refresh this publication snapshot.
